# game-one – Arkada

Žaidimų platforma: viena iOS programėlė, kurioje gyvena daug žaidimų.

| Žaidimas | iOS (SwiftUI) | Naršyklė / telefonas |
|---|---|---|
| **Planų Meistras** – sudėliok buto planą iš kambarių | `ios/Arkada.swiftpm/Games/PlanuMeistras` | `web/planu-meistras.html` |

- **iOS**: atidaryk `ios/Arkada.swiftpm` per Xcode 15+ (Mac) arba Swift Playgrounds. Išsamiau – [`ios/README.md`](ios/README.md).
- **Naršyklė**: `web/planu-meistras.html` yra vienas failas be priklausomybių. Atsidaryk Safari ir pasirink „Pridėti prie pradžios ekrano“.
- **Naujas žaidimas**: `ios/scripts/new_game.sh <PascalVardas> "<Pavadinimas>"`.
